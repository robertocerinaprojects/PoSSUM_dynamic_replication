# PoSSUM: Dynamic Replication

A workspace for reproducing the PoSSUM paper’s analyses, refitting its Stan models, and exploring results in R.

## Project status

Under construction. The complete data, model definitions, and reproducible computing environment are being assembled. The repository is not yet ready for a full replication run.

## Intended workflows

- **Explore results:** inspect saved predictions and regenerate figures and tables.
- **Refit a model:** compile and fit an original Stan model for a selected survey period and outcome.
- **Reproduce the paper:** run the complete analysis using documented inputs and settings.

Full Stan model refitting is a core requirement of this project.
